COMO RODAR O PROGRAMA NO PC
---------------------------
Instruções detalhadas: 2_programa\COMO_RODAR.txt
(iguais aos Apêndices A e B da monografia).

Resumo:
  1. Instale Python 3.10 ou 3.13
  2. No PowerShell, dentro de 2_programa\codigo:
       python -m venv venv
       .\venv\Scripts\Activate.ps1
       pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
       pip install -r requirements.txt
  3. streamlit run app/streamlit_app.py
  4. Envie exemplos\punho_fratura.jpg
